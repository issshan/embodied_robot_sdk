# 协议与接口约定

## 帧格式

| 字段 | 字节 | 编码 |
|---|---:|---|
| magic | 2 | 5A 5A |
| type | 2 | uint16，小端 |
| payload_length | 4 | uint32，小端，0-4096 |
| payload | N | 按消息类型定义 |
| crc16 | 2 | 小端，CRC16/MODBUS |

CRC初值FFFF，多项式A001，逐字节低位优先，无最终异或，覆盖帧头和负载。标准测试串123456789应得到4B37，线上为37 4B。

消息：0001心跳请求、0002心跳回复（均空负载）；1001底盘速度命令、2001模拟状态（3个小端IEEE754 binary32，依次vx m/s、vy m/s、wz rad/s）。2001是本示例约定，不是厂商协议。

## 解析策略

从流中逐字节搜索magic，确认长度上限，等待完整帧后校验CRC；CRC或长度无效时丢弃一个字节重新同步。通过后才交付回调。缓冲区为8212字节，单次网络读取1024字节；写入失败中止当前连接。每次新连接重置解析器，防止旧半帧混入新会话。

## 线程与连接

网络线程独占Socket的创建、连接、收发和关闭。发送请求复制到互斥锁保护的有界FIFO，默认最多64帧，每帧最大4106字节。不跨断线保留命令。

默认连接超时500ms，单帧发送总超时500ms；心跳每250ms发送，1000ms未收到合法回复则关闭；重连等待100ms开始，逐次翻倍至1600ms。收到过有效心跳回复的连接断开后重置退避。等待按短片段检查退出标记，无随机抖动。

连接状态仅描述TCP，启动成功不代表连接成功，发送成功仅表示入队。应用应实现业务确认、限速和设备侧安全策略。

回调在网络线程执行，数据指针只在回调内有效；不得销毁SDK、调用Init/Shutdown或执行阻塞任务。使用者必须在被捕获对象销毁前先Shutdown。

## 部署边界

平台层仅支持Windows Winsock与Linux POSIX IPv4。协议没有版本协商、认证、加密和业务ACK，仅供模拟/可信测试网络使用。未对真实机器人部署。
