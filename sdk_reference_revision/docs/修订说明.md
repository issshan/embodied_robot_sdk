# 修订说明

日期：2026-10-18。

来源：本目录原始SDK压缩包，与GitHub main提交59fa5b33a7de7113dbb4c3049c58d2894ef42038的文件结构及主要内容一致。修订目录未复制.git或账号配置，最初未上传（2026-10-21以新增目录发布）。

## 修改原因与结果

- 原CMakeLists为空：加入库、演示、测试目标以及线程/Socket链接配置。
- 原协议只封包、不校验接收CRC：引入有界流解析器、负载上限及错误重新同步，小端逐字段编码避免直接拷贝结构体布局。
- 原send只调用一次：改为总超时内循环处理短写、可重试错误和终止错误，补可注入短写测试。
- 原Socket跨线程共享及关闭：改为网络线程独占，应用只向有界队列提交，断线丢弃旧命令。
- 原无心跳、固定间隔重试：加入心跳回复检测、超时关闭、指数退避和退出取消。
- 原缺对端和测试：增加独立Python协议模拟端与自动化测试，便于无实机复现。
- 原README描述超出代码：重写范围、构建步骤、运行方式、限制和证据，不延续历史性能数字。

## 保留与新增

保留原RingBuffer基本算法、SDK类名、速度结构和回调接入思路。平台层、新接收解析器、队列与测试为本次辅助补充，不应说成2024课程或2025实习时已实现。修订版的原创归属和熟练程度仍需本人理解、修改和解释，不能由本次代码生成证明。
